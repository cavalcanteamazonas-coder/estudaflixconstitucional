# ESTUDAFLIX - Portal Acadêmico de Direito
**Desenvolvedor:** Wallace Cavalcante (3º Período de Direito)

Portal de simulados focado na banca **FGV**, desenvolvido para auxiliar estudantes na fixação de temas fundamentais do Direito Constitucional.

## 🚀 Funcionalidades
- 13 Temas abrangentes.
- Design responsivo (Prata, Branco e Dourado).
- Fundamentação jurídica baseada na CF/88.
- Interface leve e intuitiva.

## 📚 Como usar
Basta abrir o arquivo `index.html` em qualquer navegador ou acessar via GitHub Pages.
